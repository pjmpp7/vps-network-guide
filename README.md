## 买 VPS 之前，先搞清楚你需要什么

**常见的 VPS 使用场景大概分这几类：**

1. **建站/博客**：需要稳定的国际访问速度，对延迟要求不算极端，但 uptime 要高
2. **开发测试环境**：要求灵活，配置可以低一点，网络稳定就行
3. **国内用户访问加速**：这是最难搞的，需要对中国三大运营商（电信/联通/移动）都友好的线路
4. **跨境业务**：要求节点位置靠近目标市场，延迟低
5. **流量转发/代理**：对带宽要求高，需要高质量 IP

如果你是第 3 或第 4 类用户，普通的 VPS 基本上满足不了你的需求。

## 你一定听过这些词，但未必真正懂

VPS 购买过程中，你会遇到一堆术语。这里不打算写教科书，只挑最关键的说：

### CN2 GIA 是什么？

CN2 是中国电信旗下的优质骨干网络，GIA（Global Internet Access）是其中质量最高的那条。普通国际线路走的是拥挤的公共互联网，CN2 GIA 走的是专属通道，延迟更低、丢包更少，在晚高峰表现尤为稳定。

> **类比**：普通线路是国道，CN2 GIA 是高速公路专用道，不堵车还有护栏。

### 三网回程是什么？

中国用户访问海外 VPS 时，数据从你的电脑出去，经过层层路由最终到达服务器，再原路返回。"三网回程"指的是电信、联通、移动三家运营商的用户，回程路由都走优质线路（比如都走 CN2 GIA），而不是某一家走好线路、另外两家绕远路。

### 带宽限速的坑

很多低价 VPS 标称"1Gbps 带宽"，但实际上是突发带宽，平时只给你 10Mbps，流量超了直接限速。买之前要看清楚：是保证带宽还是突发带宽，月流量额度是多少。
